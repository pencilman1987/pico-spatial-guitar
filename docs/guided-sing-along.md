# 跟唱模式

目标是让零基础用户把注意力放在“扫节奏和唱歌”，而不是复刻真实吉他的指法。

## 当前交互

- 默认选中原创练习歌《一起唱》，也可切换《晚风》或“自由”伴奏。
- 面板显示当前歌词、下一句、当前/下一和弦和 4 个扫弦进度点。
- 每个小节扫 4 下；第 4 下后立即自动切到下一句和弦。
- “升调/降调”限制在 -5..+6 个半音，歌曲调性、和弦名和实际 MIDI 音高保持一致。
- 用户在“自由”模式手动选和弦时，不再自动推进歌词。

## 内容权利

当前两首歌的歌词与练习段落为本项目原创示例，不随意内置商业歌曲歌词。后续接入曲库时，应只使用已授权歌词/和弦数据或用户自己导入的内容。

## PICO 真机验收

模拟器可确认状态、排版、发声与自动换和弦逻辑，但无法代替真机的手部/控制器舒适度校准。下一轮真机重点记录：

1. 连续扫 16 下的漏触与误触数。
2. 上扫/下扫在自然速度下的触发一致性。
3. 第 4 下扫弦到新和弦提示出现的主观延迟。
4. 边唱边扫时，面板是否过高、过近或遮挡视野。
